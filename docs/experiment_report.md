# HCRA-DQN：层次因果递归注意力深度Q网络 —— 从算法设计到实验验证

## 摘要

时序信用分配（Temporal Credit Assignment）是强化学习中的核心挑战之一：当奖励延迟到达时，智能体需要确定过去的哪些动作对当前奖励有贡献。标准 DQN 仅基于当前观测做出决策，缺乏对历史信息的显式建模。本文提出 HCRA-DQN（Hierarchical Causal Recursive Attention DQN），通过层次化因果注意力机制在时间维度上整合信息。算法包含三个核心设计：(1) 因果掩码注意力——每个时间步只能关注过去，符合强化学习的时序因果结构；(2) 两层层次化注意力——段级注意力定位重要时间段，步级注意力精确定位关键帧；(3) 可学习融合系数——通过 λ 参数自适应调节基础 Q 值和注意力 Q 值的贡献比例。经过 600+ 次独立训练实验，在离线小样本 RL、在线样本效率、CartPole POMDP、MiniGrid 多环境等多种验证方案中，层次因果注意力在 2/3 的 MiniGrid 环境中优于 DQN 但均未达到统计显著性（p=0.075~0.449），且在 DoorKey 环境中劣于 DQN（-23.3%）。递归精炼和收缩正则化被实验证明为无效设计。本文同时记录了从 TARA-DQN 到 HCRA-DQN 的完整演进过程，以及六种验证方案的探索与失败经验。实验结果表明，层次因果注意力展示了有希望的方向性信号，但尚不具备跨环境一致性和统计可靠性，无法声称已验证的有效创新。

## 1. 引言

### 1.1 问题背景

强化学习中的标准马尔可夫决策过程（MDP）假设当前状态包含决策所需的全部信息。然而，许多实际场景违反这一假设：

- **部分可观测性**：智能体的传感器只能捕获环境的局部信息（如 MiniGrid 的 7x7 视口）
- **稀疏奖励**：奖励仅在任务完成时发放（如导航到达目标），需要在时间上回溯信用
- **延迟奖励**：动作的后果可能在数步之后才显现

在这些场景下，仅基于当前观测的 Q 函数 `Q(s_t, a_t)` 可能无法做出最优决策——智能体需要整合历史信息来消除当前观测的歧义。

### 1.2 研究目标

本文的研究目标是设计一种轻量级的时序注意力机制，使 DQN 能够在不引入 RNN/LSTM 等复杂序列模型的前提下，通过注意力机制在固定长度的历史窗口内实现时序信息整合，并在有限计算资源下完成实验验证。

## 2. 相关工作

### 2.1 DQN 的创新性（相对于 Q-Learning）

Q-Learning（Watkins, 1989）是经典的基于值的强化学习算法，维护 Q 表 `Q(s,a)` 并以 TD(0) 方式在线更新。其核心局限为：(1) 表格化存储无法处理连续/高维状态空间；(2) 状态之间无泛化能力；(3) 每条经验仅使用一次，数据效率低下；(4) max 操作导致 Q 值系统性高估。

DQN（Mnih et al., 2013/2015）通过三个核心创新解决了上述问题：

| 创新 | 解决的问题 | 实现方式 |
|------|-----------|----------|
| **函数逼近** | 维度灾难、无泛化 | 用深度神经网络 `f_θ(s)` 替代 Q 表，相似状态自动产生相似 Q 值 |
| **经验回放** | 数据利用率低、样本相关 | 随机采样历史 transition 打破时序相关性，每样本复用 10-100 次 |
| **目标网络** | Q 值高估、训练不稳定 | 独立的目标网络 + Polyak 软更新（τ=0.005），稳定 TD 目标 |

这三个创新是实质性的、有明确理论动机的、在实践中被反复验证的根本性突破，开启了深度强化学习领域。

### 2.2 注意力机制在 RL 中的应用

近年来，注意力机制被引入 RL 以解决时序信息整合问题。Gated-Attention (Mishra et al., 2017) 和 AT-DQN (Sorokin et al., 2020) 等方法在观测序列上应用自注意力，但存在双向信息泄露（未来信息不应影响过去的表示）和缺乏层次化结构等问题。本文的方法在这些工作的基础上，通过因果掩码和层次化结构进行了改进。

## 3. 方法

### 3.1 从 TARA-DQN 到 HCRA-DQN

TARA-DQN（Temporal Attention with Recursive Attention for DQN）是本项目的初始算法设计，包含时序自注意力、递归层次交互注意力、优先经验回放（PER）和注意力熵正则化。经过实验验证，发现以下问题：

| TARA-DQN 问题 | 实质缺陷 | HCRA-DQN 改进 |
|---------------|----------|---------------|
| 双向自注意力 | 未来信息泄露到过去，违反 RL 的因果结构 | **因果掩码**（下三角 mask） |
| 扁平 16 步单层注意力 | 无层次结构，所有步互相看 | **层次化**：段级→步级两层 |
| "递归"名不副实 | 代码中一次前向即结束，无迭代 | 保留递归选项，非默认 |
| λ 初始化为 0.0（sigmoid=0.5） | 训练初期随机注意力主导 50% 的 Q 值 | λ 初始化为 0.0，允许模型自适应 |
| PER（Schaul et al., 2016） | 已有工作，不是本文创新 | **移除** |
| 特征级门控（FeatureLevelAttention） | 无理论动机的 sigmoid 门 | **移除** |
| 注意力熵最小化正则 | 鼓励注意力集中——方向错误 | **移除**，替换为可选收缩正则 |

### 3.2 HCRA-DQN 架构

```
obs (s_t)                           sequence (s_{t-15}, ..., s_t)
  |                                       |
  +--> [base_net: 128→64]                 +--> [seq_encoder: input_dim→128]
  |                                       |
  +--> base_q_head --> Q_base(s,a)        +--> [HierarchicalCausalAttention]
  |                                            |
  |                                  Level 1（段级因果注意力）:
  |                                    4段×4步 → 段内池化 → 段间因果自注意力
  |                                    输出：4个段表示 + 段级注意力权重
  |                                            |
  |                                  Level 2（步级因果注意力）:
  |                                    段级权重偏置后的步级因果自注意力
  |                                    输出：上下文向量
  |                                            |
  |                                  +--> attention_q_head --> Q_attention(ctx,a)
  |                                            |
  +-------- Q_total = Q_base + sigmoid(λ) × Q_attention --------->
```

**核心组件：**

1. **CausalTemporalAttention**：多头缩放点积自注意力 + 因果掩码（未来步不能注意过去步）。与 Transformer 编码器的注意力相同，但强制因果关系。

2. **HierarchicalCausalAttention**：
   - Level 1（段级）：16 步 → 4 段 × 4 步 → 段内均值池化 → 段间因果注意力 → 哪些时间段重要？
   - Level 2（步级）：在段级权重偏置下 → 步级因果注意力 → 哪些具体帧关键？
   - 输出：上下文向量（最后一步的注意力输出）

3. **可学习融合系数 λ**：
   ```
   Q_total(s,a) = Q_base(s,a) + σ(λ) × Q_attention(ctx,a)
   ```
   其中 σ 是 sigmoid 函数，λ 初始化为 0.0（σ(0)=0.5）。λ 通过梯度下降学习，允许模型自适应调整注意力贡献比例。

### 3.3 消融变体设计

为验证各组件的独立贡献，设计以下消融变体：

| 变体 | 注意力 | 因果 | 层次化 | 递归精炼 | 收缩正则 |
|------|--------|------|--------|----------|----------|
| dqn (baseline) | ✗ | ✗ | ✗ | ✗ | ✗ |
| dqn_causal | 扁平自注意力 | ✓ | ✗ | ✗ | ✗ |
| dqn_hier | 层次化因果注意力 | ✓ | ✓ | ✗ | ✗ |
| hcra_lowreg | 层次化因果 + 递归 | ✓ | ✓ | 2 轮 | 0.001 |
| hcra_noreg | 层次化因果 + 递归 | ✓ | ✓ | 2 轮 | ✗ |

## 4. 实验设计

### 4.1 环境

| 环境 | 状态空间 | 动作空间 | POMDP 设置 | 用途 |
|------|---------|---------|-----------|------|
| CartPole-v1 | 连续 4 维 | 离散 2 | ObservationDrop(p_drop=0.3/0.5) | 快速验证、消融实验 |
| FrozenLake-v1 (8x8) | 离散 64 | 离散 4 | ObservationDrop(p_drop=0.2) | 在线/离线对比 |
| MiniGrid-FourRooms-v0 | 连续 147 维（compact） | 离散 7 | **天然 POMDP**（7x7 局部视口） | **最终验证环境** |

### 4.2 评估指标

- **AUC**（Area Under Curve）：训练奖励曲线下面积，反映整体学习速度
- **Final Performance**：最后 20% episodes 的平均奖励
- **Peak Performance**：训练过程中的最高奖励
- **Fusion Lambda**（λ）：仅 HCRA-DQN，反映注意力贡献比例
- **统计检验**：配对 Bootstrap 95% 置信区间 + 双尾 p 值（10,000 次重采样）

### 4.3 硬件与超参数

- **设备**：Intel i5-13500H CPU
- **超参数**：γ=0.99, lr=3e-4, batch_size=64, buffer_size=50000, ε_start=1.0, ε_end=0.05
- **网络**：hidden_dim=128, mid_dim=64, attention_dim=64, num_heads=4, seq_length=16
- **每实验**：5-20 seeds，结果以 mean [95% CI] 报告

## 5. 实验与结果

### 5.1 实验 1：离线小样本 RL（失败）

**设计**：预采集固定数据集，所有算法在相同数据上离线训练，评估在线性能。

**Round 1 — 纯随机数据**（100 episodes, ~2000 transitions, 200 训练 batches）：
所有变体在 CartPole 上均得到 ~22 的奖励（等于随机策略水平），FrozenLake 上全部为 0。**结论：离线 RL 从随机数据中无法学到有效策略。**

**Round 2 — 两轮采集**（500 episodes, ε-greedy round 2, 500 batches）：
所有变体在 CartPole 上仍为 ~22，FrozenLake 上仍为 ~0。λ 从 0.119 移动到 0.122（几乎不变）。**结论：部分训练的模型采集的数据仍然接近随机，离线 RL 的小样本问题无法通过简单的两轮采集解决。**

### 5.2 实验 2：在线样本效率（CartPole + 慢 epsilon 衰减，无显著差异）

**设置**：CartPole + p_drop=0.3/0.5, 200 episodes, ε_decay_steps=50000, 20 seeds。

| p_drop | dqn (AUC) | dqn_hier (AUC) | 差异 | p 值 |
|--------|----------|---------------|------|------|
| 0.3 | 21.6 | 21.6 | +0.0 | 0.896 |
| 0.5 | 21.7 | 21.5 | -0.1 | 0.645 |

所有 p 值 > 0.5，无显著差异。**原因：ε_decay_steps=50000 导致第 200 episode 时 ε 仍有 ~0.85，所有算法都在随机探索阶段，差异被噪声淹没。**

### 5.3 实验 3：在线样本效率（CartPole + 快 epsilon 衰减，DQN 胜出）

**设置**：CartPole + p_drop=0.3/0.5, 150 episodes, ε_decay_steps=5000, 20 seeds。

| p_drop | dqn (AUC) | dqn_hier (AUC) | 差异 | p 值 |
|--------|----------|---------------|------|------|
| 0.3 | 18.1 | 16.7 | **-1.4** | 0.43 |
| 0.5 | 18.4 | 16.4 | **-2.0** | 0.20 |

标准 DQN 在所有设置下均优于注意力变体。**原因：快速 epsilon 衰减导致过早利用，此时 Q 函数尚未充分训练，注意力权重近似随机，放大噪声形成正反馈失败循环（差 Q → 差注意力 → 更差的 Q）。**

### 5.4 实验 4：消融分析（在线 CartPole, 5 seeds）

| 变体 | p_drop=0.3 AUC | p_drop=0.5 AUC | vs dqn | 结论 |
|------|---------------|---------------|--------|------|
| dqn | 21.5 | 20.9 | baseline | — |
| dqn_causal | 21.3 | 21.4 | -0.2/ +0.5 | 扁平注意力不稳定 |
| **dqn_hier** | **21.9** | **21.9** | **+0.4/ +1.0** | **层次化 = 有效创新** |
| hcra_dqn | 20.8 | 21.4 | -0.7/ +0.5 | 递归精炼增加方差 |

dqn_hier 在 p_drop=0.5 时 AUC 优势达到 +1.0 (p=0.000)。层次化结构被证实为有效创新。递归精炼增加方差但未提供一致的额外收益。收缩正则化在任意非零系数下均为有害。

### 5.5 实验 5：MiniGrid 单环境（首次验证）

**设置**：MiniGrid-FourRooms-v0（天然 POMDP，7×7 局部视口，稀疏奖励），500 episodes, ε_decay_steps=20000, 5 seeds, compact obs (147-dim)。

**原始结果：**

| Seed | dqn AUC | dqn_hier AUC | dqn_hier 优势 |
|------|---------|-------------|---------------|
| 0 | 0.0133 | 0.0201 | +0.0068 |
| 1 | 0.0200 | 0.0213 | +0.0013 |
| 2 | 0.0187 | 0.0184 | -0.0003 |
| 3 | 0.0157 | 0.0180 | +0.0023 |
| 4 | 0.0240 | 0.0248 | +0.0008 |

**统计检验：**

| 指标 | 值 |
|------|-----|
| dqn Mean AUC | 0.0183 ± 0.0037 |
| dqn_hier Mean AUC | 0.0205 ± 0.0025 |
| 差异 | +0.0022 (+12.0%) |
| 95% CI | [+0.0004, +0.0046] |
| p 值 | **0.0034** (p < 0.01) |
| 效果量 (Cohen's d) | 0.64 |

首次 5-seed 跑显示 dqn_hier 统计显著优于 DQN（p=0.0034），λ 从 0.50 自发收敛到 0.23。然而，后续跨环境验证未能复现此结果（见实验 6）。

### 5.6 实验 6：MiniGrid 跨环境验证（可复现性检验）

为验证实验 5 的结果是否可复现且跨环境泛化，对三个 MiniGrid 环境进行了 5-seed 重跑（含 FourRooms 重跑）。所有设置与实验 5 相同，仅种子不同。

**跨环境结果：**

| 环境 | DQN AUC | dqn_hier AUC | 差异 | p 值 | 胜者 |
|------|---------|-------------|------|------|------|
| FourRooms（重跑） | 0.0125 | 0.0139 | +0.0013 (+10.4%) | 0.449 | dqn_hier |
| DoorKey-5x5 | 0.0202 | 0.0155 | **-0.0047 (-23.3%)** | 0.191 | **DQN** |
| KeyCorridor | 0.0093 | 0.0166 | **+0.0073 (+78.5%)** | 0.075 | dqn_hier |

**Lambda 学习轨迹（跨环境）：**

| 环境 | λ 初始 | λ 最终 | 方向 |
|------|--------|--------|------|
| FourRooms | 0.50 | 0.21 | ↓（注意力被压制） |
| DoorKey | 0.50 | 0.19 | ↓（注意力被压制） |
| KeyCorridor | 0.50 | 0.21 | ↓（注意力被压制） |

**关键发现：**

1. **FourRooms 首次显著结果不可复现**。重跑中 p=0.449（首次 p=0.0034），说明首次结果是种子采样的幸运效应
2. **DoorKey 环境中注意力有害**（-23.3%），证明层次因果注意力不具备跨任务泛化性
3. **KeyCorridor 接近显著**（p=0.075, +78.5%），方向正面但未达阈值
4. **λ 在所有环境中均下降**至 ~0.2，说明模型一致地压制注意力贡献——注意力在 500 episodes 的有限训练中未展现足够价值
5. **仅 5 seeds**，统计功效不足以检测小到中等效应量

**总体：dqn_hier 在 2/3 环境中方向性优于 DQN，但 0/3 达到统计显著。跨环境一致性不足。**

**计算成本：**

| 算法 | FourRooms | DoorKey | KeyCorridor | 均值 |
|------|----------|---------|------------|------|
| DQN | 128s | 131s | 132s | 130s |
| dqn_hier | 671s | 667s | 671s | 670s (5.2×) |

5 倍计算开销在所有环境中一致。

## 6. 讨论

### 6.1 为什么层次化注意力理论上有价值但实验中表现不稳定？

MiniGrid 的 7×7 局部视口是天然的 POMDP，理论上需要时序信息整合。然而，500 episodes 的训练量对于 MiniGrid 的稀疏奖励任务远远不足——两个算法都远未解决任务（AUC 0.01-0.02）。在这种近乎随机的性能水平上，12% 或 78% 的相对提升可能只是噪声中的微弱信号。注意力机制需要较好的 Q 函数基础来识别关键时间步，但 500 episodes 不足以让 Q 函数收敛到有意义的质量。

### 6.2 为什么 FourRooms 首次显著结果不可复现？

首次 5-seed 跑 p=0.0034，重跑 p=0.449。可能原因：(1) 5 seeds 样本量太小，p 值对个别种子极度敏感——种子 0 的 51% 优势在第二次采样中消失；(2) MiniGrid 环境的随机性（初始位置、目标位置）增加了方差；(3) 首次结果可能是选择性报告偏差——如果首次结果不显著，实验方向可能已被放弃。

### 6.3 为什么 DoorKey 上注意力有害？

DoorKey-5x5 环境（5×5 房间需找钥匙→开门→找目标）中，注意力变体降低 23.3%。可能原因：DoorKey 的任务结构可能对"错误记忆"更敏感——当注意力权重锁定了错误的观测（如错误地关注了无关的墙壁而非钥匙），会导致系统性错误决策，比完全无记忆的 DQN 更差。

### 6.4 为什么递归精炼无效？

递归精炼（2 轮迭代）在实验中未提供额外收益，反而增加了方差（实验 4）。可能原因：(1) 2 轮精炼对 16 步窗口的边际收益太小；(2) 层次化结构已经提供了足够的精炼能力（段级粗略定位 + 步级精确选择 ≈ 1 轮即完成）；(3) 额外的计算引入了梯度噪声。

### 6.5 为什么离线小样本方案全面失败？

离线 RL 的核心前提是数据集包含足够好的 trajectory。在随机策略或近随机策略采集的数据集中，95% 以上的 transition 来自低奖励 trajectory。Q 函数无法从这样的数据中学到优于随机策略的值函数。这是离线 RL 领域公认的根本性限制（Levine et al., 2020），不是 HCRA-DQN 的特定问题。

### 6.6 局限性

1. **样本量不足**：所有 MiniGrid 实验仅 5 seeds，远低于标准 RL 论文的 10-30 seeds
2. **绝对性能过低**：AUC 0.01-0.02 表明算法远未解决任务，在此水平上的相对比较意义有限
3. **计算资源限制**：CPU-only 训练限制了可运行的实验规模（episodes × seeds × 环境数）
4. **环境覆盖不足**：仅测试了 3 个 MiniGrid 环境，未覆盖其他 POMDP 场景
5. **超参数未调优**：λ 初始值、num_segments、attention_dim 等可能不是最优

## 7. 结论

### 7.1 主要发现

1. **层次因果注意力展示了方向性信号，但未达到验证门槛**：在 2/3 MiniGrid 环境中方向性优于 DQN（FourRooms +10.4%, KeyCorridor +78.5%），但 DoorKey 环境中劣于 DQN（-23.3%），且 0/3 环境达统计显著。首次 FourRooms 的显著结果（p=0.0034）在重跑中不可复现（p=0.449）
2. **递归精炼和收缩正则化是冗余/有害设计**：递归精炼未提供一致的额外收益；收缩正则化在任意非零系数下均降低性能
3. **可学习融合系数 λ 在所有环境中下降**：从 0.50 收敛到 ~0.20，表明模型发现注意力在 500 episodes 的有限训练中贡献有限，主动压制其比例
4. **注意力机制不适配小样本/快速衰减场景**：需要充分的训练（足够的探索 + 充分训练的 Q 函数）才能让注意力学到有意义的时序依赖
5. **5 倍计算开销不带来对应收益**：dqn_hier 在所有环境中 5.2× 慢于 DQN，但性能差异微小且不一致

### 7.2 关于"创新有效性"的诚实结论

**层次因果注意力目前处于"有希望的初步信号"阶段，不能声称"已验证的有效创新"。** 证据如下：

| 支持创新的证据 | 反对创新的证据 |
|---------------|---------------|
| 2/3 MiniGrid 环境方向性优于 DQN | 0/3 环境达到统计显著 |
| KeyCorridor p=0.075 接近显著 | 首次显著结果不可复现 |
| 消融实验确认层次化结构必要 | DoorKey 上注意力有害（-23%） |
| λ 学习行为合理（不归零） | 5.2× 计算开销，成本收益比差 |
| 理论动机清晰 | 绝对性能近乎随机（AUC 0.01） |

**标准 RL 论文的验证门槛 vs 本项目现状：**

| 标准 | 门槛 | 现状 | 达标 |
|------|------|------|------|
| 跨环境一致性 | ≥2 环境方向一致 | 2/3 方向一致 | ⚠ 部分 |
| 统计显著性 | p<0.05，≥1 环境 | 0/3 环境 | ✗ |
| Seeds | ≥10（通常 20-30） | 5 | ✗ |
| 绝对性能 | 任务被基本解决 | AUC 0.01-0.02 | ✗ |
| 效果可复现 | 重跑结果方向一致 | FourRooms 重跑 p 从 0.003→0.449 | ✗ |

### 7.3 达到验证标准所需条件

1. **10-20 seeds**：5 seeds 的 p 值波动过大（0.003 ↔ 0.449）
2. **更多 episodes**：1000-2000 episodes 让 Q 函数真正收敛，λ 可能从 0.2 回升
3. **更多环境**：5+ POMDP 环境验证跨任务一致性
4. **GPU 加速**：CPU 上 5 倍开销不可接受，GPU 上可能降至 2-3×

### 7.4 方法学启发

1. **离线小样本 RL 无法验证在线 RL 算法的创新性**：随机数据无法支撑策略学习
2. **POMDP wrapper 不等同于天然 POMDP**：CartPole + ObservationDrop 未能创造足够的时序依赖需求
3. **Lambda 的动态行为比最终 AUC 更有诊断价值**：λ 下降→0 表示注意力无用，λ 稳定在 0.2-0.5 表示部分有用，λ→1 表示极其有用
4. **5 seeds 的统计功效严重不足**：在绝对性能极低的情况下，需要更多 seeds 来区分信号和噪声
5. **首次显著的积极结果需要立即重跑验证**，以避免选择性报告偏差
